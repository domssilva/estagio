# Sistema de Apoio à Validação de Diplomas

Este é um sistema web desenvolvido como parte do estágio obrigatório do curso de Engenharia de Software pela UNIGRAN Europa.  
O objetivo é **auxiliar brasileiros no processo de validação de diplomas no sistema educacional espanhol**, oferecendo informações claras, interativas e acessíveis por meio de uma plataforma web leve e intuitiva.

---

## 🧩 Funcionalidades

- ✅ Página com **etapas detalhadas** do processo de validação
- ✅ **Checklist interativo** para autoavaliação da documentação
- ✅ Página de **perguntas frequentes (FAQ)**
- ✅ Interface responsiva (HTML + Bootstrap)
- ✅ Backend em Flask (Python)
- ✅ Templates dinâmicos com Jinja2

---

## 🚀 Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/seu-repo.git
cd seu-repo
```

2. (Opcional) Crie e ative um ambiente virtual:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

3. Instale as dependências necessárias:
```bash
pip install -r requirements.txt
```

4. Crie um arquivo .env com a seguinte variável:
```bash
SECRET_KEY=sua-chave-secreta-aqui
```

6. Execute o servidor:
python main.py
